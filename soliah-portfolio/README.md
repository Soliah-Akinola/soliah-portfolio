# Soliah Akinola: Portfolio

Personal portfolio built with React, Vite and Tailwind CSS.

## Run locally

npm install
npm run dev

## Before deploying

1. Add your photo as `public/profile.jpg`
2. Add your CV as `public/resume.pdf`
3. Paste your Formspree form ID into `FORMSPREE_ID` in `src/data.js`
4. Edit any text in `src/data.js`

## Deploy

Push to GitHub, then import the repo on Vercel. Vercel detects Vite automatically.
